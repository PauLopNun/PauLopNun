### [Supply Chain Simulator](https://github.com/PauLopNun/supply-chain-simulator-workshop)
<sub>Team project · GFT Technologies 2026 · 14 stars</sub>

Distributed simulation of a supply chain: five microservices (time and map, factories, warehouses, transport and reporting) that only talk to each other through **RabbitMQ events**, each one designed as a DDD bounded context.

I **co-designed the system architecture** and built the [**Transport Service**](https://github.com/PauLopNun/transport-service): truck registration, assignment and movement across the grid, event contracts with Spring Cloud Contract, Testcontainers integration tests and **deployment on AWS behind an Elastic Load Balancer**.

### [FlowBoard](https://github.com/PauLopNun/FlowBoard)
<sub>Final DAM project · Android + Kotlin backend</sub>

Notion-style workspace for Android. **Real-time collaborative document editor** built on a CRDT engine over WebSockets (11 block types, slash commands, Markdown shortcuts, live presence), plus tasks with list, Kanban and calendar views, group chat, shared workspaces with invite codes and email notifications.

Ktor backend with 13 PostgreSQL tables, JWT and Google Sign-In, **deployed on Render**. CI builds the APK and publishes a GitHub Release on every push.

### [Telecom Notification Service](https://github.com/PauLopNun/telecom-notification-service)
<sub>Personal project · Python backend</sub>

Microservice that receives network and service alerts, stores them and exposes a REST API to query them by client, event type and status. Hexagonal architecture with FastAPI and SQLAlchemy kept out of the domain, async repositories, Alembic migrations and a **100% coverage gate** with Testcontainers.
